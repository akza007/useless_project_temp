# RIVAL RUSH: RISE OF THE SEVEN

A 2D retro arcade beat-'em-up game built with HTML5, JavaScript (ES6+), and Phaser.js 3.

Inspired by retro arcade combat and energy, facing seven increasingly difficult rivals.

---

## Story & Rivals Structure

* **Protagonist**: Scott Pilgrim
* **Story Partner**: Ramona Flowers (appears in the victory sequence)

### The Seven Rivals
1. **Stage 1**: Matthew Patel — First Evil Ex (Mystic Fireballs & Demon Chicks)
2. **Stage 2**: Lucas Lee — Skater / Action Star (Skateboard Grind Charge & Stuntman Slam)
3. **Stage 3**: Roxie Richter — Half-Ninja (Teleportation & Shadow Whip Slash)
4. **Stage 4**: Todd Ingram — Vegan Bassist (Telekinetic Pulses & Forcefield)
5. **Stage 5**: Kyle & Ken Katayanagi — Conjoined-Twin Duo Boss fight (counts as Rivals #5 & #6)
6. **Stage 6**: Brutal Pre-Final Endurance Gauntlet (escalating enemy waves)
7. **Stage 7**: Gideon Graves — Final Boss (4-Phase Arena Battle)

---

## Controls

| Key | Action |
|---|---|
| **A** / **←** | Move Left |
| **D** / **→** | Move Right |
| **W** / **↑** / **Space** | Jump |
| **J** | Light Attack (Punch / Kick combo) |
| **K** | Heavy Attack / Special Energy Attack (if energy ≥ 30) |
| **L** | Invincible Dash |
| **ESC** | Pause Menu |

## How to Run

### Option 1: Using the included lightweight server
```bash
node server.js
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 2: Using Vite
```bash
npm install
npm run dev
```
